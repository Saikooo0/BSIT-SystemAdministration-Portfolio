## Challenges Encountered

**1. Virtualization was disabled in the BIOS.**
VirtualBox showed an error that VT-x/AMD-V was not available, so my virtual machine would not start. I restarted my computer, entered the BIOS/UEFI settings, enabled virtualization, and the VM ran normally afterward.

**2. The ISO files took a long time to download.**
The Ubuntu and Windows ISO files are several gigabytes each, and a slow connection caused one download to fail halfway. I used a more stable connection, downloaded during off-peak hours, and checked that the files were complete before using them.

**3. The virtual machine was slow and had a small display.**
My first Ubuntu VM lagged and used a tiny screen resolution. I increased the RAM and CPU cores in the VM settings, then installed VirtualBox Guest Additions to enable full-screen resolution and smoother performance.

## Reflection
This week I learned that a System Administrator's work begins with a well-prepared environment. Before this activity, I only thought of installing software as clicking "Next" until it finished. Now I understand that each tool has a specific purpose. Git and GitHub teach me version control, which lets me track changes, undo mistakes, and document my work. Visual Studio Code gives me a flexible editor for writing scripts and configuration files.

VirtualBox was the most valuable tool for me. Creating virtual machines showed me that I can safely practice installing operating systems, changing settings, and even breaking things without damaging my real computer. Working with both Ubuntu and Windows also showed me that a System Administrator must be comfortable in more than one operating system, since real workplaces often use both.

The challenges I faced taught me patience and troubleshooting. Fixing the BIOS virtualization error and the slow VM showed me that reading error messages carefully and searching for reliable documentation are essential skills. Problems rarely come with a ready-made answer, so I have to investigate step by step.

Setting up my GitHub and LinkedIn accounts also made me realize that my career starts now. By recording my progress each week, I am building a portfolio that I can show to future employers. These tools will help me manage servers, automate tasks, and solve problems efficiently, and I look forward to building on this foundation in the coming weeks.
